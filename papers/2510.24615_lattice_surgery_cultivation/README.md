# Efficient magic state cultivation with lattice surgery

Yutaka Hirano, Riki Toshio, Tomohiro Itogawa, Keisuke Fujii (2025), [arXiv:2510.24615](https://arxiv.org/abs/2510.24615).

## Where the circuits are

The paper links to [yutakahirano/msc-ls](https://github.com/yutakahirano/msc-ls), which I used at `main` commit `e4c90b0`. The figure code lives on
branch `experiment-2025-sep`. `data/` holds sample Stim circuits generated by `src/`. Two of them contain the magic-state part:
- `inject-check-3`: injection plus double check on the Steane code;
- `lattice-surgery-complementary-gap-3-to-5-to-7`: the end-to-end protocol, with lattice surgery from the Steane code into d=5 and then d=7
  surface codes.

Both use the S/S_DAG proxy of Gidney et al. The other files are Clifford sub-circuits (surface-code expansion, error-detection tests).

## What I did

- `tex/`: arXiv source. I removed the figures.
- `stim_src/msc-ls/`: README, LICENSE, `data/` and the generator `src/` (without tests).
- `make_circuits.py` converts both circuits by blanket S→T (the d=3 rule) and strips instruction tags:
  - Clifft rejects tags.
  - Tsim fails to parse any tag that contains the token ` T`, e.g. `TICK[Encode T]` ("Targets must be separated by spacing").
  - The `DETECTOR[POST-SELECTION]` indices are saved in `stim/*.postselection.json`.
- Checks: both circuits are sampled noiselessly in Tsim (2048 shots), and all detector values equal the proxy's.
  - Every detector is deterministic except the end-to-end file's last one. It repeats the final logical-Y readout (same records as
    `OBSERVABLE_INCLUDE(0)`), so like the observable it reads 1 with probability 0.857 ≈ 1 − 0.146 for a T state.
